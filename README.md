# EncoDecode

A simple Bash script to encode and decode text using Base64 and Base32.

## Installation

1. Clone the repository:
```
git clone https://github.com/Vansh8182/ip-geolocation-lookup.git
```

2. Enter the folder:
```
cd ip-geolocation-lookup
```

3. Make the script executable:
```
chmod +x ip-lookup.sh
```

4. Run it:
```
./ip-lookup.sh
```

## Usage

When prompted, enter any IP address:

```
Enter IP address: 8.8.8.8
CITY: Ashburn
REGION: Virginia
COUNTRY: United States
ZIP: 20149
LAT: 39.03
LON: -77.5
TIMEZONE: America/New_York
```
